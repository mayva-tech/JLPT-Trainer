# KanjiVG stroke data

`kanjiStrokes.data.ts` is generated from **KanjiVG**
(https://kanjivg.tagaini.net, https://github.com/KanjiVG/kanjivg),
copyright © Ulrich Apel, licensed under the Creative Commons
Attribution-Share Alike 3.0 licence
(https://creativecommons.org/licenses/by-sa/3.0/).

The generated file contains the stroke paths of the kanji used in this
app's vocabulary, unchanged apart from whitespace. As a derivative of
KanjiVG it is shared under the same licence (CC BY-SA 3.0).

Attribution where the strokes are shown:
- In the app: credited here and in the generated file's header.
- On YouTube: the Shorts upload text adds the line
  "Stroke order: KanjiVG (kanjivg.tagaini.net), CC BY-SA 3.0"
  to the description of every Short that animates strokes.
